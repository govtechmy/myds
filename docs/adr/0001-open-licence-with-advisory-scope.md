# DESIGN.md is CC BY 4.0, and its "government only" scope is advisory

DESIGN.md and CONTEXT.md are an unofficial, independent description of MYDS, which itself has no licence. We licensed their text under CC BY 4.0 so that agencies can copy it and GovTech Malaysia can adopt it upstream. Because the licence is open, the notice limiting the file to official services is a request we can't enforce. The real limit on using the Malaysia flag and the Jata Negara is Malaysian law. The licence is stated inside DESIGN.md and the README, not in a root LICENSE file, because it covers only those two files. The rest of the repository is upstream MYDS.

## Considered Options

- **A custom licence that binds reuse to official services.** Rejected: it isn't an open licence, so upstream couldn't simply adopt the file, and agencies would need legal review before copying it.
- **No licence.** Rejected: others could only read the file, not copy it into their own projects.
- **A root LICENSE file.** Rejected: it would look like a licence for all of MYDS, which isn't ours to license.

## Consequences

A CC BY licence can't be withdrawn from copies already made. If the notice is removed or upstream adopts the file, reusers still only have to credit the author.
