## Gambaran Keseluruhan

Dialog HTML/CSS MYDS menyediakan komponen modal untuk aplikasi yang tidak menggunakan React. Ia memastikan pengendalian keadaan yang betul, ciri-ciri kebolehcapaian, dan keharmonian reka bentuk merentasi antara muka sektor awam.

## 1. Persediaan

Ikut langkah-langkah ini untuk menyediakan gaya dialog dalam projek HTML anda.

**Susunan Import yang Disyorkan**
Pastikan untuk memuatkan stylesheet dalam urutan ini untuk memastikan penggayaan yang betul:

```html
<link rel="stylesheet" href="css-reset.css" />  <!-- rujuk kepada ResetCSS -->
<link rel="stylesheet" href="dialog.css" />     <!-- rujuk kepada DialogCSS -->
<link rel="stylesheet" href="dialog-dark.css" /> <!-- rujuk kepada DialogDarkCSS -->
```

Ini menjamin bahawa:

1. CSS reset digunakan terlebih dahulu.
2. Gaya asas dialog mengatasi reset di mana perlu.
3. Gaya tema gelap digunakan terakhir, supaya ia boleh mengatasi kedua-dua reset dan gaya dialog asas apabila diperlukan.

### Langkah 2 - Sertakan fon yang diperlukan

Fon Inter adalah sebahagian daripada garis panduan reka bentuk MYDS. Tambahkannya di dalam `<head>` anda:

```html
<link
  href="https://fonts.googleapis.com/css2?family=Inter:wght@400;500;600;700&display=swap"
  rel="stylesheet"
/>
```

`<head>` anda sepatutnya kelihatan seperti ini:

```html
<head>
  <!-- Fon Inter -->
  <link
    href="https://fonts.googleapis.com/css2?family=Inter:wght@400;500;600;700&display=swap"
    rel="stylesheet"
  />

  <!-- Stylesheet Sistem Reka Bentuk -->
  <link rel="stylesheet" href="css-reset.css" />
  <link rel="stylesheet" href="dialog.css" />
  <link rel="stylesheet" href="dialog-dark.css" />
</head>
```

## 2. Penggunaan

Dialog menggunakan elemen HTML `<dialog>` asli dengan struktur berikut:

```html
<button class="button-myds-primary" onclick=openDialog()>
  Buka Dialog
</button>

<dialog>
  <div class="dialog-header">
    <h2 class="dialog-title">Tajuk Dialog</h2>
  </div>

  <div class="dialog-content">
    <p>Kandungan dialog diletakkan di sini.</p>
  </div>

  <div class="dialog-footer">
    <div class="dialog-actions-group">
      <button class="button-myds button-myds-secondary" type="button" onclick=closeDialog()>
        Tindakan Sekunder
      </button>
      <button class="button-myds button-myds-primary" type="button" onclick=closeDialog()>
        Tindakan Utama
      </button>
    </div>
  </div>
  
  <button class="dialog-close" onclick=closeDialog() aria-label="Tutup">
    <svg viewBox="0 0 24 24" fill="none" xmlns="http://www.w3.org/2000/svg">
      <path d="M18 6L6 18M6 6L18 18" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round"/>
    </svg>
  </button>
</dialog>
```

## 3. Struktur

Dialog terdiri daripada elemen-elemen berikut:

- **Butang Pencetus**: Membuka dialog menggunakan `showModal()`
- **Elemen Dialog**: Elemen dialog HTML5 asli
- **Pengepala Dialog**: Mengandungi tajuk
- **Kandungan Dialog**: Kawasan kandungan utama
- **Pengaki Dialog**: Mengandungi butang tindakan yang dibungkus dalam `dialog-actions-group`
- **Butang Tutup**: Diletakkan secara mutlak di sudut kanan atas

## 4. Keadaan

Setiap butang dalam dialog menyokong:

- **Lalai**
- **Hover**
- **Fokus**
- **Dilumpuhkan**

## 5. Anatomi

| Pemilih                  | Tujuan                              |
| ------------------------ | ------------------------------------ |
| `dialog`                 | Elemen dialog HTML asli dengan penggayaan tersuai |
| `dialog::backdrop`       | Lapisan latar belakang (digayakan melalui pseudo-element) |
| `.dialog-header`         | Bahagian pengepala |
| `.dialog-title`          | Penggayaan tajuk dialog |
| `.dialog-content`        | Kawasan kandungan |
| `.dialog-footer`         | Bahagian pengaki |
| `.dialog-actions-group`  | Pembungkus untuk butang pengaki |
| `.dialog-close`          | Butang tutup |
| `.button-myds`           | Gaya butang asas |
| `.button-myds-primary`   | Butang tindakan utama |
| `.button-myds-secondary` | Butang tindakan sekunder |
| `.page-center`           | Memusatkan kandungan pada halaman |

## 6. Penyesuaian

Anda boleh mengatasi gaya lalai dalam stylesheet anda.
Contoh:

```css
dialog {
  max-width: 40rem; /* Lebar dialog tersuai */
}

.dialog-title {
  font-size: 1.25rem; /* Saiz tajuk tersuai */
}
```

## 7. JavaScript

Pelaksanaan menggunakan API dialog asli:

```javascript
const dialog = document.querySelector('dialog');

// Buka dialog
function openDialog() {
  dialog.showModal();
}

// Tutup dialog
function closeDialog() {
  dialog.close();
}

// Tutup apabila klik di luar (boleh ditolak)
dialog.addEventListener('click', (e) => {
  const rect = dialog.getBoundingClientRect();
  if (
    e.clientX < rect.left ||
    e.clientX > rect.right ||
    e.clientY < rect.top ||
    e.clientY > rect.bottom
  ) {
    closeDialog();
  }
});
```

## 8. Kebolehcapaian

- Dibina dengan elemen `<dialog>` asli
- Navigasi papan kekunci disokong (kekunci ESC menutup dialog secara lalai)
- Elemen butang semantik
- Cincin fokus yang kelihatan untuk pengguna papan kekunci
- Ikon SVG dengan viewBox yang betul untuk butang tutup
